# Listing Creation

Use this skill only for agents adding inventory. Infer every explicit fact available in each
message, preserve prior Listing values, and treat corrections as narrow updates. Never invent
property facts or expose internal state, record IDs, or workflow terminology.

Ask one short question at a time and never re-ask supplied information. Resolve Condo and Geo
relationships before writing them. Treat unit identifiers as optional free-form metadata; if the
agent does not know the unit, continue without it and do not ask again. Ask for photos before
publishing, but do not require them.
Summarise the captured Listing and ask for confirmation before publishing. Use concise, natural
estate-agent language.
